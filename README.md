UNIT CONVERTER
===============

A simple dark-themed unit conversion website built with Vanilla HTML, CSS, and JavaScript.

OVERVIEW
--------
The Unit Converter makes unit conversions easy to understand by showing both the final answer and a step-by-step explanation of how the calculation is performed.

STEP-BY-STEP SOLUTIONS
----------------------
The converter explains how each calculation is performed.

A typical solution contains:
1. Identify the conversion.
2. Apply the correct conversion factor or formula.
3. Perform the calculation.
4. Display the final answer.

Example:
1000 mL = 1 L

Step 1 - Identify the conversion
Convert 1000 milliliters into liters.

Step 2 - Apply the conversion factor
1000 mL / 1000 = 1 L

Step 3 - Calculate
1000 / 1000 = 1

Step 4 - Final Answer
1000 mL = 1 L

TEMPERATURE
-----------
Celsius to Fahrenheit:
°F = (°C × 9/5) + 32

Fahrenheit to Celsius:
°C = (°F - 32) × 5/9

Celsius to Kelvin:
K = °C + 273.15

OHM'S LAW
---------
Values:
- Voltage (V)
- Current (A)
- Resistance (Ω)

Formulas:
V = I × R
I = V / R
R = V / I

The solution explains the known values, formula, substitution, calculation, and final answer.
